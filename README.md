# agentic_jee_system Flow

This project defines a declarative CrewAI Flow in `src/agentic_jee_system/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/agentic_jee_system/flow.yaml` to change the flow. Add reusable crews under `src/agentic_jee_system/crews/`, custom Python tools under `src/agentic_jee_system/tools/`, and shared knowledge files under `src/agentic_jee_system/knowledge/`.
